This guide demonstrates how to migrate a complete site from Contentful into Strapi — including blog posts, authors, categories, and a product catalog — without writing migration code. Instead, a Claude Code skill reads your Contentful content model and performs the migration automatically, transferring formatted text, images, and relationships between content types.
